# 📅 IENID Task Shifts Calendar

Welcome to the **IENID Task Shifts Calendar**! This web application is designed to help the IENID community organize and manage task shifts effortlessly. Whether it's scheduling preaching, praise, prayer, or offerings, this tool makes it simple and visual. 🌟

## 🎯 Purpose
The main goal of this app is to assist in creating and visualizing task shifts for the IENID community. Keep everyone on the same page with an intuitive calendar interface that supports drag-and-drop functionality for easy adjustments. 👥

## ✨ Features
- **📆 Interactive Calendar**: Navigate through months and years with ease.
- **🌙 Dark/Light Theme Toggle**: Switch themes to suit your preference.
- **🎨 Customizable Task Colors**: Assign colors to different task types for better visualization.
- **🔄 Drag-and-Drop Tasks**: Use SortableJS to rearrange tasks within days.
- **📸 Export as Image**: Capture your calendar as an image using html2canvas.
- **🗑️ Clear Month**: Reset the entire month with one click.
- **📝 Task Management**: Add, edit, or delete tasks via a modal interface.

## 🚀 How to Use
1. **Open the App**: Simply open `calendar.html` in your web browser.
2. **Select Month/Year**: Use the dropdowns to jump to any month and year.
3. **Add Tasks**: Click on a date to open the task modal. Choose a task type (Pregação, Louvor, Oração, Ofertas), enter a name, pick a color, and save.
4. **Edit/Drag Tasks**: Double-click tasks to edit, or drag them to different days.
5. **Export**: Hit the "Exportar" button to download the calendar as an image.
6. **Theme Toggle**: Click the moon/sun button to switch themes.

## 🛠️ Technologies Used
- **HTML5**: Structure of the app.
- **CSS3**: Styling with Bootstrap for responsiveness.
- **JavaScript**: Core functionality, including calendar logic and interactions.
- **Bootstrap 5**: For responsive design and components.
- **SortableJS**: Enables drag-and-drop for tasks.
- **html2canvas**: For exporting the calendar as an image.
